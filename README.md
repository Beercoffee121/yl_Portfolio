# YL · 项目作品集

这是一个用于集中展示产品项目的个人作品集，内容涵盖智能应用、企业内部业务系统与网站原型设计。

作品集以项目本身为主要展示对象，通过项目背景、个人参与、主要设计内容、工作流或原型以及在线体验入口，呈现不同项目的目标与方案。

## 展示内容

每个项目主要包含以下内容：

- 项目背景与需要解决的问题
- 个人参与的项目环节
- 主要产品设计与业务流程
- Dify 工作流截图或 Figma 交互原型
- 在线 Demo、原型入口及必要的体验说明


## 体验说明

- Dify Demo 与 Figma 原型将通过外部链接打开。
- 在线 Demo 可能受接口或服务状态影响，无法使用时仍可通过页面中的工作流截图了解项目结构。
- 公交相关演示数据不作为真实、实时的出行信息来源。
